# Changelog

Release tags are named `harness-vX.Y.Z`. A run records the tag and commit it branched from, so
results always refer to one exact harness, protocol and task set.

## 1.0.0

First public release: the orchestrator, the starting harness, the protocol and the task packages
listed in [docs/tasks.md](docs/tasks.md). The channel for contributing to Flex-RSI (submitting and
verifying results) will open as soon as possible.
